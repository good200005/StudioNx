## 1. 목표 / 배경
- 브라우저만으로 **곡을 만들 수 있는 DAW**를 완성합니다. 이 Phase의 핵심(타임라인·피아노롤·악기·이펙트·저장)이 Studio Nx MVP의 중심입니다.
- 이후 Phase(출력, 분리, AI 추천, 협업)가 모두 이 시퀀서의 데이터 구조(트랙·클립·패턴·노트·디바이스·오토메이션)를 기반으로 동작하므로, **데이터 모델을 안정적으로 설계**하는 것이 가장 중요합니다.

## 2. 범위
### In scope
- 트랜스포트: 재생/정지/일시정지, 루프 구간, BPM·박자 설정, 메트로놈
- 타임라인(어레인지 뷰): 트랙 추가/삭제/순서변경, 클립 배치·이동·길이조절·복제·삭제, 그리드 스냅
- 샘플 라이브러리: 외부 파일 드래그앤드롭 업로드 → 개인 라이브러리 저장, 검색·태그, 브라우저 로컬 캐시
- MIDI 입력: 피아노롤 클릭 입력, **Web MIDI API로 외부 MIDI 키보드** 실시간 연주/녹음, `.mid` 파일 가져오기
- **스케일·코드 도우미** (피아노롤)
- **오디오 녹음** (마이크/오디오 인터페이스)
- 웹 기반 가상악기(synth, 샘플러) 및 이펙트 플러그인(EQ, 컴프레서, 리버브, 딜레이 등)
- **트랙 아코디언**: 각 트랙 바로 밑으로 펼쳐지는 편집 영역. Ableton Live식 **디바이스 체인 뷰** + FL Studio Patcher식 **패처(노드 연결) 뷰**를 융합 (하단 고정 패널은 두지 않음)
- **오토메이션 레인** (아코디언의 [오토메이션] 탭)
- **패턴(링크 클립)** 과 **클립 런처(세션 뷰)**
- 믹서: 트랙 헤더의 볼륨·팬·뮤트·솔로·미터, 마스터 트랙
- **하단 패널(토글형)**: 버튼을 눌렀을 때만 나타나는 패널. 이 Phase에서는 틀(컨테이너)만 만들고, 내용인 **Nyxi 도우미(AI)** 는 Phase 5, **협업 톡방**은 Phase 6에서 채움
- **시퀀서 캐릭터 Nyxi(닉시)**: FL Studio의 Fruity Dance(FL Chan)처럼 화면 안에서 춤추는 캐릭터. 동시에 **AI 도우미의 아이콘·얼굴** 역할. **외형·애니메이션 에셋은 별도 AI 플랫폼에서 제작**하고, 이 프로젝트는 연동만 담당
- **Nyxi 카드형 디바이스 UI**: 이펙터·가상악기를 Nyxi 캐릭터 기반 카드로 표시하고, 세부 설정은 카드를 클릭해 여는 **상세 설정 모달**에서 조작
- **프로젝트 템플릿** (적용 전 확인창 필수)
- **튜토리얼 모드** (Nyxi가 안내)
- **UI 커스터마이징**(테마·색·크기·레이아웃·단축키)과 **커맨드 팔레트**
- 프로젝트 저장/불러오기, 실행 취소/다시 실행(Undo/Redo)

### Out of scope
- VST 등 네이티브 플러그인 로드 → 지원하지 않음 (웹 기반만)
- 파일 출력 → Phase 3
- **Nyxi 캐릭터 외형·애니메이션·카드 아트 제작** → 별도 AI 플랫폼에서 제작해 제공받음. 이 프로젝트에서는 만들지 않고 **연동 규격**(§4.9 FR-288)만 정의
- 상황 인지 팁(Nyxi 팁) → PRD 05 §4.5 (이 문서에서는 설정 항목만 다룸)

### 4.6 WASM 플러그인 인터페이스 (C++ 연동 규격 초안)
> C++ 구현은 사용자가 직접 합니다. AI는 아래 **입출력 규격**만 문서로 정의합니다.

| 항목 | 규격 (초안) |
|---|---|
| 빌드 | Emscripten으로 `.wasm` + JS glue 생성, AudioWorkletProcessor에서 로드 |
| 초기화 | `init(sampleRate, maxBlockSize)` |
| 파라미터 | `setParam(paramIndex, value)` — 인덱스는 `param_schema` 순서와 동일 (오토메이션도 이 함수로 전달) |

| 메모리 | 입출력 버퍼는 WASM 힙에 미리 할당, 매 블록마다 새로 할당하지 않음 |

## 5. 비기능 요구사항
| 구분 | 요구사항 |
|---|---|
| 오디오 성능 | DSP는 AudioWorklet 스레드에서 처리. 16트랙 + 트랙당 이펙트 3개 + 오토메이션 레인 10개 재생 시 끊김 없음(데스크톱 Chrome 기준) |
| 지연 | 외부 MIDI 키보드 입력 → 소리 출력 지연 체감 30ms 이하 목표 |
| 녹음 정확도 | 레이턴시 보정 후 녹음 클립 위치 오차 ±5ms 이내 |
| UI 성능 | 타임라인·피아노롤·오토메이션은 Canvas 렌더링 권장, 노트 수천 개에서도 스크롤·줌이 부드러울 것 |
| 저장 | 저장 실패 시 사용자에게 알리고 로컬(브라우저 저장소)에 임시 백업 |
| 보안 | 업로드 파일은 확장자 + MIME + 실제 헤더 검사, 파일명은 서버에서 UUID로 변경. 마이크 권한은 녹음 시점에만 요청 |
| 브라우저 | 오디오 재생은 사용자 클릭 이후 `AudioContext.resume()` (자동재생 정책 대응) |
| 라우팅 변경 | 패처 연결을 바꿀 때 오디오 그래프는 재생을 멈추지 않고 교체(짧은 페이드로 클릭 노이즈 방지) |
| 캐릭터 | 캐릭터 표시 중에도 CPU 사용 증가가 체감되지 않을 것. 캐릭터 기능 오류가 시퀀서 동작을 막지 않도록 분리 |
| 디바이스 모달 | 모달을 열고 닫아도 오디오가 끊기지 않을 것. 모달 열기 100ms 이내, 시각화는 60fps 목표(오디오 스레드와 분리) |
| 접근성 | 고대비 모드, 키보드만으로 주요 기능 사용 가능(커맨드 팔레트), 색에만 의존하지 않는 상태 표시 |
| 품질 | 오디오 엔진·플러그인 변경 시 **오디오 회귀 테스트**(PRD 00 §7.1) 통과 필수 |

| GET | `/tags?category=` | 태그 목록 |
| GET | `/plugins` | 사용 가능한 플러그인 목록 + `param_schema` |
| GET | `/plugins/{id}/presets` | 시스템 + 내 프리셋 |
| POST | `/plugins/{id}/presets` | 내 프리셋 저장 |
| DELETE | `/presets/{preset_id}` | 내 프리셋 삭제 |
| POST | `/projects/{id}/import-midi` | `.mid` 파일 → 트랙/패턴/클립/노트 생성 (프론트 파싱으로 대체 가능) |
| GET | `/templates` | 시스템 + 내 템플릿 목록 |
| GET | `/templates/{id}/preview` | 템플릿 적용 시 변경 요약 (**확인창 내용**) |
| POST | `/templates` | 현재 프로젝트를 내 템플릿으로 저장 |
| POST | `/projects/{id}/apply-template` | 템플릿 적용 (body: template_id, mode=ADD/REPLACE, `confirmed=true` 필수) |
| DELETE | `/templates/{id}` | 내 템플릿 삭제 |
| GET | `/users/me/settings` | UI 설정(테마·단축키·캐릭터·하단 패널·튜토리얼) 조회 |
| PATCH | `/users/me/settings` | UI 설정 부분 저장 (캐릭터 위치 이동 등은 디바운스 후 전송) |

> 패처 라우팅·오토메이션·패턴·씬은 `/projects/{id}/full` 저장·조회에 함께 포함됩니다.
> 저장 방식: Phase 2는 **전체 저장(PUT full)** 으로 단순하게 시작하고, Phase 6에서 변경 단위(operation) 저장으로 확장합니다.
> 템플릿 적용 API는 `confirmed=true`가 없으면 400을 반환합니다 — 프론트 확인창을 거치지 않은 적용을 서버에서도 막습니다.

## 10. 완료 기준 (Acceptance Criteria)
- [ ] 외부 오디오 파일을 드롭하면 라이브러리에 저장되고, 새로고침 후에도 남아 있다.
- [ ] 라이브러리 샘플을 타임라인에 끌어 놓고 재생하면 정확한 박자 위치에서 소리가 난다.
- [ ] 피아노롤에서 클릭으로 입력한 노트가 선택된 신스로 재생된다.
- [ ] 외부 MIDI 키보드 연주가 실시간으로 들리고, 녹음하면 MIDI 클립으로 남는다.
- [ ] 트랙에 이펙트 3개를 걸고 순서를 바꾸거나 바이패스하면 소리에 반영된다.
- [ ] BPM을 바꿔도 클립·노트·오토메이션 포인트의 마디 위치가 유지된다.
- [ ] 저장 → 페이지 새로고침 → 불러오기 시 모든 트랙·클립·패턴·노트·디바이스·오토메이션 값이 동일하다.
- [ ] Undo/Redo가 클립 이동, 노트 추가/삭제, 파라미터 변경, 템플릿 적용에 대해 동작한다.
- [ ] 다른 회원의 샘플 파일 URL로 직접 접근해도 받을 수 없다.
- [ ] 트랙을 펼치면 바로 밑에 아코디언이 열리고, 디바이스를 드래그해 체인에 끼워 넣을 수 있다.
- [ ] 패처 뷰에서 병렬 분기(예: 원음 + 디스토션 혼합)를 연결하면 소리에 반영되고, 저장 후 다시 열어도 연결이 유지된다. 순환 연결은 만들 수 없다.
- [ ] 하단 패널은 기본적으로 숨겨져 있고, 버튼을 누를 때만 나타난다.
- [ ] Nyxi가 페이지 안에 떠 있고, 재생 시 BPM에 맞춰 춤추며, 숨김/위치 설정이 다음 접속에도 유지된다. 상단바 도우미 버튼 아이콘이 Nyxi 얼굴이다.
- [ ] 필터 컷오프 오토메이션을 그리면 재생 시 소리가 그에 맞게 변하고, 출력(Phase 3) 결과에도 반영된다.
- [ ] C minor 스케일을 고르면 스케일 밖 음이 흐려지고, 스케일 스냅·코드 스탬프가 동작한다.
- [ ] 마이크 녹음 클립이 레이턴시 보정되어 박자에 맞게 놓인다.
- [ ] 링크 복제한 패턴 하나를 고치면 같은 패턴의 모든 클립이 바뀌고, [고유하게 만들기] 후에는 따로 바뀐다.
- [ ] 클립 런처에서 씬을 실행하면 다음 마디 경계에서 해당 클립들이 동시에 재생된다.
- [ ] 템플릿 적용 시 **반드시 확인창**이 뜨고, [취소]하면 아무것도 바뀌지 않는다. 교체 적용 전에는 자동 스냅샷이 생긴다.
- [ ] 첫 접속 시 튜토리얼을 진행할 수 있고, 중간에 나갔다 와도 이어서 할 수 있다.
- [ ] 테마·UI 배율·단축키를 바꾸면 즉시 적용되고, 다른 브라우저에서 로그인해도 유지된다. 단축키 충돌 시 경고가 뜬다.
- [ ] Ctrl+P로 "트랙 추가"를 검색해 실행할 수 있다.
- [ ] 디바이스가 Nyxi 카드로 표시되고 핵심 노브를 카드에서 바로 돌릴 수 있으며, 카드를 클릭하면 상세 설정 모달이 열려 전체 파라미터를 조작할 수 있다(재생은 끊기지 않음).
- [ ] 외부에서 받은 에셋 폴더를 교체하면 코드 수정 없이 캐릭터·카드 아트가 바뀐다. 에셋이 없으면 플레이스홀더가 보인다.
- [ ] 두 번째로 연 프로젝트는 샘플을 캐시에서 읽어 첫 오픈보다 빨리 열린다.
- [ ] 저장 용량을 넘으면 업로드가 거부되고 안내가 표시된다.
