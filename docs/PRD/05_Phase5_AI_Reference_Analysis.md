## 1. 목표 / 배경
- "이 곡 같은 느낌을 내고 싶은데 어떻게 설정해야 할지 모르겠다"는 문제를 해결합니다.
- 사용자가 **레퍼런스(링크 또는 파일)** 와 **장르(직접 입력 또는 태그 클릭)** 를 주면, AI가 음향 특징을 분석하고 Studio Nx의 플러그인·믹서에 **바로 적용 가능한 설정값**으로 추천합니다.
- 추천은 "정답"이 아니라 **출발점**입니다. 적용 후 사용자가 자유롭게 수정할 수 있어야 합니다.

## 2. 범위
### In scope
- 레퍼런스 등록: 링크(YouTube 등) / 오디오 파일 업로드 / 라이브러리 샘플 선택
- 장르 지정: 텍스트 직접 입력 또는 장르 태그 클릭(복수 선택)
- 분석: 템포, 키, 라우드니스(LUFS), 트루피크, 다이내믹 레인지, 대역별 스펙트럼 밸런스, 스테레오 폭, 악기 구성 추정
- 추천 4종: **Synth 프리셋**, **Plugin(이펙트) 프리셋**, **믹싱 설정**(트랙별 볼륨/팬/EQ/컴프), **마스터링 설정**(마스터 체인, 목표 LUFS)
- 추천 적용: 미리보기(A/B) → 적용 → Undo 가능
- 내 프로젝트 vs 레퍼런스 비교(라우드니스, 스펙트럼)
- **Nyxi 도우미 (AI)**: FL Studio의 Gopher 같은 대화형 도우미. 하단 패널에서 Studio Nx 사용법·작곡/믹싱 질문에 답함. 시퀀서 캐릭터 **Nyxi가 도우미의 아이콘·얼굴** (§4.4)
- **Nyxi 팁 (상황 인지)**: 사용자가 묻기 전에 Nyxi가 클리핑·저역 겹침 등 문제를 먼저 알려줌. 기본은 "중요한 것만", **프로젝트가 5개쯤 되면 확인창으로 계속 받을지 물어봄** (§4.5)
- **레퍼런스 기반 새 프로젝트**: 분석 결과로 BPM·키·트랙 구성·추천 체인을 갖춘 새 프로젝트 생성 (적용 전 확인창 필수)
- AI 사용량 표시·제한

### Out of scope
- 레퍼런스 곡의 멜로디·코드 자동 채보 → 추후 검토
- 자동 작곡/생성 → 지원하지 않음
- 저작권 있는 원본 오디오의 영구 보관·재배포 → 하지 않음 (아래 §5 참고)

### 4.4 Nyxi 도우미 — AI 도우미 (FL Studio Gopher식)
> 시퀀서의 **하단 패널(토글형, PRD 02 §4.8)** 의 [Nyxi] 탭에서 동작하는 대화형 AI 도우미입니다.
> FL Studio의 서비스명 "Gopher"는 쓰지 않고, 시퀀서 캐릭터 **Nyxi(닉시)**(PRD 02 §4.9)를 도우미의 아이콘·얼굴로 씁니다. 캐릭터 외형은 별도 AI 플랫폼에서 제작합니다.

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-531 | 상단바 **Nyxi 아이콘** 버튼(또는 Ctrl+K) → 하단 패널이 올라오며 Nyxi 탭 표시. 입력창에 질문 → 답변 스트리밍 표시 | 필수 |
| FR-532 | 답변 범위: ① Studio Nx 기능 사용법(도움말 문서 기반) ② 작곡·사운드 디자인·믹싱 일반 지식 ③ 현재 프로젝트에 대한 조언 | 필수 |
| FR-533 | **프로젝트 문맥 제공**: 질문 시 현재 프로젝트 요약(BPM, 키, 트랙 목록, 선택 트랙의 디바이스 체인/패처 구성, 최근 분석 결과)을 함께 보내 맞춤 답변. 오디오 원본은 보내지 않음 | 필수 |
| FR-534 | 도움말 근거: Studio Nx 사용법 질문은 `docs/help/` 도움말 문서를 검색해 근거로 사용(RAG), 답변에 해당 도움말 링크 표시 | 권장 |
| FR-535 | **액션 버튼**: 답변이 화면 조작으로 이어질 수 있으면 버튼 제공 (예: "Bass 트랙에 Compressor 추가", "패처 뷰 열기", "레퍼런스 분석 시작"). 실행 전 확인, 실행 후 Undo 가능 | 권장 |
| FR-536 | 대화 기록 저장(`assistant_messages`), 프로젝트별로 이어서 보기, [대화 지우기] | 필수 |
| FR-537 | Nyxi 대화는 **개인 전용** (협업 멤버에게 보이지 않음). 협업자에게 공유하고 싶으면 [톡방에 공유] 버튼으로 답변을 채팅에 붙여넣기 (Phase 6 이후) | 권장 |
| FR-538 | 사용량 제한(사용자별 일일 질문 수) 및 실패 시 "잠시 후 다시 시도" 안내 | 필수 |
| FR-539 | **캐릭터 연동**: 답변 생성 중엔 Nyxi가 "생각 중" 동작, 패널이 닫혀 있으면 답변 완료 시 Nyxi 아이콘 배지 + 캐릭터가 답변 요약을 말풍선으로 말함. 말풍선 클릭 → [Nyxi] 탭 열림 | 필수 |
| FR-540 | **빠른 질문**: 캐릭터 클릭 → 캐릭터 옆 짧은 입력창. 답변은 말풍선(요약) + 전체 내용은 [Nyxi] 탭에 기록 | 권장 |
| FR-541 | 튜토리얼(PRD 02 §4.15) 진행 중 질문하면 현재 튜토리얼 단계를 문맥으로 함께 전달 | 권장 |

### 4.5 Nyxi 팁 — 상황 인지 (먼저 알려주기)
> 질문형 도우미(§4.4)와 달리, Nyxi가 작업 상태를 보고 **먼저** 말풍선으로 알려줍니다. 잔소리가 되지 않도록 기본값은 조용하게 두고, **사용자가 익숙해지면(프로젝트 5개 무렵) 계속 받을지 확인창으로 묻습니다.** 상세 배경: [Ai_feedback_moreExplain.md](../Ai_feedback_moreExplain.md) §1

**팁 종류**
| 구분 | 팁 (감지 조건) | 판단 방식 | 버튼 예시 |
|---|---|---|---|
| 중요 | 마스터 클리핑 (재생 중 마스터 피크 0 dBFS 초과 3회 이상) | 규칙 (미터 값) | [리미터 추가] [볼륨 -3dB] |
| 중요 | 트랙 클리핑 (특정 트랙 미터가 계속 빨간색) | 규칙 | [게인 -6dB] |
| 중요 | 오디오 끊김 (언더런 연속 발생) | 규칙 (Sentry 지표와 같은 데이터) | [무거운 트랙 보기] |
| 중요 | 저장 안 함 (30분 이상, 자동 저장 꺼짐) | 규칙 | [지금 저장] |
| 중요 | 저장 용량 90% 초과 | 규칙 | [용량 정리] |
| 작곡 조언 | 킥·베이스 저역 겹침 (50~100Hz 동시 강세) | 클라이언트 주파수 분석 | [사이드체인 설정 열기] |
| 작곡 조언 | 음량 목표 벗어남 (출력 직전 LUFS > -8) | LUFS 측정 | [마스터링 추천 보기] |
| 작곡 조언 | 스케일 밖 음 다수 (키 설정 시) | 프로젝트 데이터 | [스케일 밖 노트 선택] |
| 작곡 조언 | 곡 앞 빈 구간 4마디 이상 (출력 시) | 프로젝트 데이터 | [출력 범위 조정] |

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-561 | 팁 레벨: **끄기 / 중요한 것만(기본) / 모두**(작곡 조언 포함). 환경 설정(PRD 02 FR-2166a)에서 **언제든 수동 변경** | 필수 |
| FR-562 | **익숙해짐 확인창**: 사용자의 프로젝트가 **5개**(설정값)에 도달한 뒤 시퀀서를 처음 열 때 1회 표시 — "Studio Nx에 꽤 익숙해지셨네요! Nyxi 팁을 계속 받을까요?" [계속 받기] [중요한 것만] [끄기]. 팁 레벨이 이미 '끄기'면 표시하지 않음. 표시 여부는 `tips_state`에 기록해 다시 묻지 않음 | 필수 |
| FR-563 | 표시 타이밍: **재생을 멈췄을 때만** 표시(재생·드래그 중엔 대기열에 보관), **녹음 중에는 절대 표시 안 함** | 필수 |
| FR-564 | 빈도 제한: 같은 팁은 프로젝트당 1회(또는 24시간 1회), 전체 팁은 10분에 최대 1개 | 필수 |
| FR-565 | 말풍선 메뉴: [이 팁 다시 보지 않기] [팁 끄기] [왜 그런가요?] — "왜 그런가요?"는 Nyxi 도우미(§4.4)에게 설명을 요청(AI 사용량에 포함) | 필수 |
| FR-566 | 조용한 모드: 캐릭터 창이 숨겨져 있으면 말풍선 대신 상단바 Nyxi 아이콘에 작은 점(●) → 클릭 시 팁 표시 | 필수 |
| FR-567 | 판단은 **브라우저에서 규칙·오디오 분석으로 처리**(LLM 호출 없음). 문장은 팁별 템플릿 사용 | 필수 |
| FR-568 | 협업 중에는 팁을 **현재 사용자의 행동과 관련된 경우에만** 표시(예: 내가 담당·잠금한 트랙, 내가 누른 출력). 다른 멤버에게는 보내지 않음 | 권장 |
| FR-569 | 팁 규칙은 목록(레지스트리)으로 관리해 추가·수정이 쉽도록 하고, 각 규칙의 오탐 여부를 회귀 테스트 프로젝트로 검증 | 권장 |

## 5. 비기능 요구사항 / 정책
| 구분 | 요구사항 |
|---|---|
| 저작권·약관 | 외부 링크의 오디오는 **분석 목적으로만 임시 사용 후 삭제**, 특징값(수치)만 저장. 각 플랫폼 이용약관을 확인해 허용되지 않는 방식이면 파일 업로드 방식만 제공 |
| AI 모델 | 특징 추출은 오디오 분석 라이브러리(예: librosa, pyloudnorm, essentia 등 후보), 해석·추천은 LLM 또는 규칙 기반 + LLM 조합. 사용 모델/버전은 `model_version`에 기록 |
| 신뢰성 | LLM 출력은 JSON 스키마로 강제하고, 범위 밖 값은 클램프 또는 재요청. 실패 시 규칙 기반 기본 추천으로 대체 |
| 비용 | 같은 레퍼런스 재분석 시 기존 결과 재사용(캐시) |
| 시간 | 3분 곡 기준 분석+추천 1분 이내 목표 (분리 사용 시 제외) |
| 개인정보 | 외부 AI API로는 오디오 원본이 아닌 **추출된 특징값만** 전송하는 것을 기본으로 함 |

## 6. 화면 구성
- `studioNx.html` 우측 **AI 패널** (토글)
  1. 레퍼런스 입력: 링크 입력창 / 파일 드롭존 / [라이브러리에서 선택]
  2. 장르: 텍스트 입력 + 장르 태그 칩(클릭 선택)
  3. [분석하기] → 진행 표시
  4. 분석 결과: 수치 카드, 스펙트럼 차트, 요약
  5. 추천 탭: Synth | Plugin | Mixing | Mastering — 카드별 [미리듣기] [적용] [프리셋 저장] + 이유 설명
  6. 비교 탭: 내 곡 vs 레퍼런스 (LUFS, 대역 밸런스)
- `studioNx.html` **하단 패널 [Nyxi] 탭** (Nyxi 아이콘 버튼 클릭 시에만 표시)
  - 대화 목록(질문/답변, 답변 안 액션 버튼, 도움말 링크), 입력창, [대화 지우기]
  - 입력창 위 "프로젝트 문맥 포함" 토글 (기본 켜짐)

## 9. AI 역할 구분

|---|---|

| JavaScript | 패널 상태 관리, A/B 미리듣기, 적용 로직 **템플릿**만 |
| Backend | 레퍼런스/분석/추천 라우터, 특징 추출·추천 생성 서비스 **템플릿**만. 분석 파이프라인·프롬프트·Nyxi(대화/RAG) 서비스는 요청 시 AI 구현 |

| DB | Phase 5 테이블 생성, 장르 태그 시드 데이터, DB.md 갱신 |

## 10. 완료 기준 (Acceptance Criteria)
- [ ] 파일 업로드 + 장르 태그 선택으로 분석하면 BPM·키·LUFS·스펙트럼 밸런스가 표시된다.
- [ ] 장르를 텍스트로만 입력해도 분석·추천이 동작한다.
- [ ] 4종(Synth / Plugin / Mixing / Mastering) 추천이 각각 1개 이상 생성되고 이유 설명이 붙는다.
- [ ] 모든 추천값이 해당 플러그인의 `param_schema` 범위 안에 있다.
- [ ] 추천을 적용하면 소리에 즉시 반영되고 Undo로 되돌릴 수 있다.
- [ ] 마스터링 추천 적용 후 출력(Phase 3)한 결과의 LUFS가 목표값 ±1 LU 안에 든다.
- [ ] 링크 분석 후 서버에 원본 오디오 파일이 남아 있지 않다.
- [ ] [이 레퍼런스로 새 프로젝트]를 누르면 확인창에 생성 내용이 요약되고, [적용]해야만 프로젝트가 만들어진다.
- [ ] 일일 AI 사용 한도를 넘으면 분석·질문이 막히고 남은 시간이 안내된다.
- [ ] Nyxi 답변 중엔 캐릭터가 생각 중 동작을 하고, 패널이 닫혀 있으면 답변 요약을 말풍선으로 보여준다.
- [ ] 마스터가 클리핑되면 재생을 멈춘 뒤 Nyxi가 팁을 보여주고, [리미터 추가]가 동작한다. 재생·녹음 중에는 팁이 뜨지 않는다.
- [ ] 다섯 번째 프로젝트를 만든 뒤 시퀀서를 열면 팁 유지 여부 확인창이 한 번만 뜨고, 선택이 설정에 저장된다.
- [ ] 환경 설정에서 팁을 끄면 어떤 팁도 표시되지 않는다.
- [ ] 하단 패널의 Nyxi에게 Studio Nx 사용법을 물으면 관련 도움말 근거와 함께 답한다.
- [ ] "이 프로젝트 BPM이 몇이야?"처럼 프로젝트 관련 질문에 현재 프로젝트 정보로 정확히 답한다.
- [ ] Nyxi 대화는 새로고침 후에도 남아 있고, 협업 멤버에게는 보이지 않는다.
