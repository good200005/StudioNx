# Studio Nx — PRD 03. Phase 3: 오디오 출력 (Export)

| 항목 | 내용 |
|---|---|
| 기획서 기능 | 5) wav 및 mp3 등 오디오 파일 형식에 따라 output하는 기능 |
| 선행 Phase | Phase 2 (시퀀서, 믹서, 플러그인) |
| 관련 페이지 | `studioNx.html` (출력 모달), `myProject.html` (출력 이력, 선택) |
| 전체 개요 | [00_PRD_Overview.md](00_PRD_Overview.md) |

---

## 1. 목표 / 배경
- 시퀀서에서 만든 곡을 **WAV / MP3 (+FLAC)** 파일로 내보내 실제로 쓸 수 있게 합니다. 이 Phase까지 끝나면 **MVP 완성**입니다.
- 출력 결과는 "시퀀서에서 들리는 소리와 동일"해야 하므로, 실시간 재생과 같은 오디오 그래프를 사용해 렌더링합니다.

## 2. 범위
### In scope
- 전체 곡 / 루프 구간 / 지정 구간 출력
- 포맷: WAV, MP3, FLAC(권장)
- 옵션: 샘플레이트, 비트뎁스(WAV/FLAC), 비트레이트(MP3), 정규화(Normalize) 여부, 끝부분 꼬리(리버브 tail) 길이
- 출력 진행률 표시, 완료 후 다운로드, 출력 이력 조회
- 출력 결과를 내 샘플 라이브러리에 추가(선택)

### Out of scope
- 트랙별 개별 출력(Stem Export) → 추후 검토 (구조상 `export_jobs`에 옵션 컬럼 추가로 확장 가능)
- 영상 포맷, 스트리밍 플랫폼 직접 업로드 → 지원하지 않음

## 4. 기능 요구사항
| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-301 | 출력 모달: 포맷, 범위(전체/루프/직접 지정), 샘플레이트(44.1k/48k), 비트뎁스(16/24/32f), MP3 비트레이트(128/192/320), 정규화, tail 길이(초) | 필수 |
| FR-302 | **렌더링 방식 — 기본: 클라이언트 렌더링(`render_mode='CLIENT'`)** — `OfflineAudioContext`에 동일한 오디오 그래프(악기·이펙트·믹서)를 구성해 실시간보다 빠르게 렌더링 | 필수 |
| FR-303 | WAV 인코딩: 클라이언트에서 PCM → WAV 헤더 작성 | 필수 |
| FR-304 | MP3 / FLAC 인코딩: 렌더링한 WAV를 서버로 업로드 → 서버에서 인코딩(예: ffmpeg) → 결과 저장. 또는 클라이언트 인코더(WASM) 사용 — 구현 시 선택 | 필수 |
| FR-305 | 출력 작업을 `export_jobs`에 기록: 상태(PENDING → PROCESSING → DONE/FAILED), 진행률, 결과 경로, 오류 메시지 | 필수 |
| FR-306 | 진행률 표시: 클라이언트 렌더링 진행률 + 서버 인코딩 상태(폴링, 예: 1초 간격) | 필수 |
| FR-307 | 완료 시 다운로드 버튼. 파일명 기본값: `{프로젝트명}_{YYYYMMDD_HHmm}.{ext}` | 필수 |
| FR-308 | "라이브러리에 추가" 옵션: 결과를 `samples`에 `source='EXPORT'`로 등록 | 권장 |
| FR-309 | 출력 이력: 프로젝트별 최근 출력 목록, 재다운로드, 삭제 | 권장 |
| FR-310 | 렌더링 중 시퀀서 편집은 막거나(모달), 렌더링 시작 시점의 상태 스냅샷을 사용 | 필수 |
| FR-311 | 출력 결과 클리핑 감지: 피크가 0dBFS를 넘으면 경고 표시 | 권장 |
| FR-313 | 렌더링에 **오토메이션·패처 라우팅·링크 클립(패턴)** 이 모두 반영됨 (타임라인 기준) | 필수 |
| FR-314 | 출력 시작 전 저장 용량 확인(PRD 01 FR-135). 출력 파일은 30일 후 자동 정리(이력은 남고 파일만 삭제, 정리 7일 전 알림) | 필수 |
| FR-312 | (확장) 서버 렌더링(`render_mode='SERVER'`) — 저사양 기기 대응. C++/WASM 엔진을 서버에서도 쓸 수 있을 때 검토 | 추후 |
| FR-315 | **트랙별 따로 출력(stems)** (2026-10-06, [Sequencer_Feature_Gaps.md](../Sequencer_Feature_Gaps.md) B6): 출력 모달에서 [전체 믹스다운 / 트랙별] 선택. 트랙별이면 트랙(그룹·리턴 포함)마다 WAV 를 만들어 zip 으로 묶음. 이펙트·센드 포함 여부 선택 → `export_jobs.export_mode='STEMS'` | 권장 |

## 5. 비기능 요구사항
- 3분 길이, 16트랙 프로젝트 기준 WAV 출력이 데스크톱에서 실제 재생 시간보다 빠르게 끝날 것.
- 출력 결과와 시퀀서 재생 결과가 들어서 구별되지 않을 것(같은 그래프, 같은 파라미터).
- 출력 렌더러는 **오디오 회귀 테스트**(PRD 00 §7.1)의 렌더링 엔진으로도 재사용.
- 서버 인코딩은 백그라운드 작업으로 처리해 API 응답을 막지 않음.
- 결과 파일은 일정 기간(예: 30일) 후 정리 가능하도록 `created_at` 기준 정책 마련.
- 다운로드는 요청자 또는 프로젝트 멤버만 가능.

## 6. 화면 구성
- `studioNx.html` 상단바 **[Export]** 버튼 → 출력 모달
  - 옵션 영역 → [출력 시작] → 진행 바 → 완료 시 [다운로드] [라이브러리에 추가]
  - 하단에 "최근 출력" 목록 (포맷, 일시, 크기, 다운로드)

## 7. API 초안 (FastAPI)
| Method | Path | 설명 |
|---|---|---|
| POST | `/projects/{id}/exports` | 출력 작업 생성 (옵션 저장, `export_id` 반환) |
| POST | `/exports/{export_id}/upload` | 클라이언트 렌더링 WAV 업로드 → 필요 시 서버 인코딩 시작 |
| GET | `/exports/{export_id}` | 상태·진행률 조회 |
| GET | `/exports/{export_id}/download` | 결과 파일 다운로드 |
| GET | `/projects/{id}/exports` | 출력 이력 |
| DELETE | `/exports/{export_id}` | 결과 삭제 |
| POST | `/exports/{export_id}/to-library` | 결과를 `samples`에 등록 |

## 10. 완료 기준 (Acceptance Criteria)
- [ ] 같은 프로젝트를 WAV / MP3 / FLAC으로 각각 출력해 다운로드할 수 있다.
- [ ] 출력 파일의 길이·샘플레이트·비트뎁스(비트레이트)가 선택한 옵션과 일치한다.
- [ ] 출력 결과가 시퀀서 재생 소리와 동일하게 들린다(이펙트, 볼륨, 팬 반영).
- [ ] 루프 구간 출력 시 해당 구간만 담긴다.
- [ ] 진행률이 표시되고, 실패 시 원인 메시지가 표시되며 `export_jobs.status='FAILED'`로 기록된다.
- [ ] "라이브러리에 추가"한 결과를 다시 타임라인에 배치할 수 있다.
