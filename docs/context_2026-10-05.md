### 3.5 시퀀서 기본 배치 (사용자 PDF + 대화로 정한 것)
원본: 사용자 `studionx/frontend-reference/images/sequencer reference/sequencer 기본 배치.pdf`, 정리 `docs/Sequencer_Layout_Mockup.md`, 목업 `docs/page_mockups/sequencer/layout/01~12` (소스 `_source/layout.html?s=1..12`, `node shot.mjs ..`).

| 영역 | 정한 것 |
|---|---|
| 헤더 | 유사도 목업 Ableton 60 : FL 40 의 두 줄 헤더 (PAT/SONG, 큰 시간, 힌트 줄, 패턴 선택, Snap·Key·Chord) |
| 왼쪽 | 버튼 줄 — 파일 5분류(Samples·Presets·Plugins·Patterns·Automation) + AI 제안 Records·Reference·Favorites / Members·Chat. 파일 패널: Upload 버튼·끌어 넣기, **검색은 맨 아래**. 협업 패널은 평소 숨김 |
| 트랙 | Ableton 50 : FL 50 디자인, 트랙 위 오토메이션 선 없음. **한 트랙 = 악기 하나**. 머리: 켜기/끄기(FL) · V(펼침) · 이름/악기 · **M·S·●(Cubase식)**. MIDI 클립은 **패턴 노트를 음 높이·길이대로 미리보기**, 샘플 클립은 **파형**. 마지막 트랙 아래 `＋ Add Track` (트랙 머리와 같은 크기) |
| 트랙 펼침 (V) | [Instrument] [Effects — 오른쪽 ＋ 직렬, 아래 ＋ 병렬, 병합 버튼] [Connect to Another] [Mixer — 미터·볼륨·팬] |
| Connect to Another | `Connect` None ⇄ Connected · `Track`(number) · `Plugin`(select) 세 칸만. 연결되면 Mixer 꺼짐, 사이드체인 입력이면 예외(켜짐) |
| 오토메이션 | 모드(A)에서 패턴 흐리게(25%), 그 위에 곡선. 놓인 패턴에 적용. **패턴 끝을 넘어 빈 칸까지 가능, 다음 패턴 시작점은 못 넘음**. 빈 칸에 새 패턴이 들어오면 창: Trim(추천) / Split / Undo placement |
| 레이어링 | ① 같은 멜로디: INSTRUMENTS 칸 `＋ Add instrument`, 악기마다 볼륨·팬·Solo ② 다른 멜로디·옥타브: 별도 트랙 + Connect(`Instruments (layer)`) → 받는 트랙에 `<from Track X>` 줄 병렬 |
| 아래 칸 | 평소 없음. MIDI 패턴 클릭 = 피아노 롤, 샘플 클릭 = 샘플 설정, Nyxi 더블 클릭 = Agent 조언·채팅 |
| Nyxi | 재생 BPM 에 맞춰 춤(fruity dance), 더블 클릭 → 조언·채팅 |
| 화면 글자 | 영어 (협업 채팅·Nyxi 채팅 내용은 사용자 언어) |
