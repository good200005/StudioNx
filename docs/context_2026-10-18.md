## 5. 작업 규칙 (변경 없음, 2026-10-17 기준)
- JS와 백엔드는 작업 단위마다 함수를 전부 이어서 구현하고, 함수 1개당 설명 문서(md+PDF)를 남깁니다. 작업 단위가 끝나면 함수 문서 **합본 PDF**와 **개요 ai-note**를 만들고, 사용자 검토는 작업 단위가 끝난 뒤 한 번에 받습니다.
- JS 실제 코드는 전통 문법만 씁니다. 최신 문법은 문서에만 적습니다. C++(`studionx/native/`)는 손대지 않습니다.
- AI가 찍는 화면 캡처는 처음부터 `docs/screenshots/YYYY-MM-DD_주제/`에 저장합니다. 디자인 목업은 `docs/page_mockups/<화면>/`입니다.
- 커밋·푸시는 사용자가 요청할 때만, PR 병합도 요청할 때만 합니다. 병합 뒤에 YouTrack을 갱신하고 다음 작업을 요약합니다.
- 문서는 `docs/AI_Doc_Template_Guide.md`를 먼저 읽고 씁니다. ~합니다체, 조사·어미를 살린 완성된 문장, "·"로 잇지 않고 쉼표와 조사를 쓰며, 산문에서 엠대시(—)는 쓰지 않습니다(H1의 "NN — 제목" 형식만 유지). PDF는 고친 문서의 것만 다시 만듭니다.
- PowerShell을 씁니다(`&&` 미지원, `cmd1; if ($?) { cmd2 }`). 한글 콘솔은 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`과 `$env:PYTHONIOENCODING="utf-8"`로 맞춥니다. 줄 번호로 `sed`를 돌리지 않고 내용으로 찾아 바꾸는 파이썬을 파일로 써서 실행합니다.
