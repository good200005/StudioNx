## 3. 알려진 한계

| 항목 | 설명 |
|---|---|
| 마디 길이 | 눈금자와 클립 격자는 4/4 마디(3840 tick)로 고정입니다. 박자를 바꿔도 마디 폭은 그대로입니다. 실제로 바꾸려면 눈금자, 스냅, 클립 폭, 재생 위치를 함께 고치는 개편이 필요합니다. |
| 메트로놈 | 화면 버튼이 엔진에 연결되지 않아(`sequencer-ui.js`의 `options.metronome`, `options.countIn`은 알림만 띄움) 소리로는 확인하지 못했습니다. 연결할 때 `sequencer-meter.js`의 목록을 `setMeterChanges`에 넘겨야 합니다. |
| 되돌리기 기록 | 프로젝트를 다시 열면 비워집니다. |
| 박자 프리셋 | 8개(`4/4, 3/4, 2/4, 5/4, 6/8, 7/8, 12/8, 6/4`)만 순환합니다. 다른 박자는 API로만 넣을 수 있습니다. |
