## 1. 무엇을 만들었나

S1-13에서 서버 API와 재생, 내보내기 쪽은 이미 갖췄지만, 화면에서 변경점을 만들 방법이 없었습니다. 이번에 그 화면을 채웠습니다.

| 기능 | 설명 |
|---|---|
| 찍기 | 빈 곳을 클릭하면 변경점이 생깁니다. |
| 끌기 | 위치와 BPM을 함께 바꿉니다. |
| 전환 방식 | `Shift`+클릭으로 `STEP`과 `LINEAR`를 바꿉니다. |
| 지우기 | 점을 더블클릭합니다. |
| 저장 | 400ms 모아서 `PUT /projects/{id}/tempo-changes`로 보냅니다. |
| 재생 반영 | `sequencer-devices.js`의 목록을 바꾸므로 재생과 WAV 내보내기가 바로 따릅니다. |

백엔드는 바꾸지 않았습니다.

## 3. 설계 결정

| 결정 | 이유 |
|---|---|
| 박자 줄은 이번에 하지 않음 | 서버에 `meter_changes` 모델이 없고, 마디 길이가 바뀌면 눈금자, 스냅, 클립 폭이 모두 달라집니다. |
| 세로 범위를 점에서 계산 | 예전 목업은 130~170 BPM으로 고정이어서 그 밖의 값을 그릴 수 없습니다. |
| 끄는 동안 범위 고정 | 범위가 계속 바뀌면 점이 손을 따라오지 못합니다. |
| 끌지 않으면 다시 그리지 않음 | 다시 그리면 더블클릭이 끊깁니다. |
