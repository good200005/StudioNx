# AI 구현 설명 91 — S1-15 오토메이션과 클립 페이드

| 항목 | 내용 |
|---|---|
| 작업 | S1-15: 트랙 볼륨, 팬, 악기와 이펙트 노브의 오토메이션 저장과 재생, 오디오 클립 페이드 |
| 작성 | Claude (AI), 2026-11-15, 사용자 검토 |
| 함수 문서 | 백엔드 316~318, 프런트 JS 319~322 |

## 1. 무엇을 만들었나

| 기능 | 설명 |
|---|---|
| 오토메이션 레인 | 트랙마다 대상(볼륨, 팬, 악기 노브, 이펙트 노브)을 골라 곡선을 그립니다. 점은 찍기, 끌기, 더블클릭 삭제를 지원합니다. |
| 저장 | `PUT /tracks/{id}/automation`이 한 레인의 점을 통째로 바꿉니다. 점이 없으면 레인을 지웁니다(204). |
| 내보내기 | WAV 내보내기에도 오토메이션이 반영됩니다(레인이 있으면 0.1초 창). 클립 페이드는 재생과 같은 코드라 처음부터 반영됩니다. |
| 재생 | 재생 중 매 tick 곡선 값을 구해 믹서, 이펙트, 악기에 덮어씁니다. 정지하면 원래 값으로 돌아갑니다. |
| 클립 페이드 | 오디오 클립 양끝의 길이와 곡선을 핸들로 편집하고 `PATCH /clips/{id}`로 저장합니다. 재생은 음량 곡선으로 예약합니다. |
| 병렬 이펙트 | 같은 변경에 들어간 기능입니다. 이펙트를 앞 이펙트와 나란히 연결합니다. |

## 2. 문서 지도

| 번호 | 내용 |
|---|---|
| 백엔드 316 | 모델과 스키마 (`automation_lanes`, `automation_points`) |
| 백엔드 317 | 서비스 (권한, 대상 검증, 점 통째 교체) |
| 백엔드 318 | API와 `/full` 포함, 시험 30건 |
| JS 319 | 곡선 값 계산과 페이드 배율 (순수 함수) |
| JS 320 | 오토메이션 레인 화면과 저장 |
| JS 321 | 클립 페이드 편집 |
| JS 322 | 재생과 불러오기 연결 |

## 3. 설계 결정

| 결정 | 이유 |
|---|---|
| 레인 하나를 통째로 교체 저장 | 점 편집은 한꺼번에 바뀌는 일이 많아, 부분 수정 규칙보다 단순하고 순서가 어긋나지 않습니다. |
| 악기 레인은 `track_instrument_id`, 이펙트 레인은 `track_plugin_id` | 두 번호는 서로 다른 테이블의 번호입니다. 처음에는 이펙트 칸 하나만 있어 악기 레인 저장이 500 오류로 실패했고, 칸을 나누어 해결했습니다. |
| 덮어쓰기는 재생 중에만, 복사본으로 | 사용자가 정한 원래 값을 보존합니다. |
| 곡선 식을 화면과 재생이 공유 | 그린 모양과 들리는 소리가 같습니다. |
| 템포와 박자 줄 편집은 이 작업에서 제외 | 화면 줄이 정적 표시이고, 별도 작업으로 분리하기로 했습니다. |
