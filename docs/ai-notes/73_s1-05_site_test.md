## 1. 이 시험이 보는 것
S1-05는 화면에서 마우스로 끄는 작업이 아니라 소리와 시간을 다루는 부분이라, 시험 방법이 S1-06과 다릅니다. 계산 규칙(시간 변환, 스케줄 계산, 메트로놈 판정)은 소리나 시계 없이도 확인할 수 있어 Node에서 모두 시험했습니다(누계 298개). 실제 소리(`AudioContext`)는 브라우저에서만 확인할 수 있습니다.

이 문서는 그중 **브라우저와 실제 소리로 확인한 부분**을 한 곳에 모은 것입니다.

## 2. 시험 방법
| 방법 | 무엇을 | 어떻게 |
|---|---|---|
| 데모 페이지 (헤드리스 Chrome) | `audio-demo.html` | 페이지를 열어 모듈 4개(`timing`, `scheduler`, `metronome`, `engine`)가 모두 로드되고 엔진이 만들어지는지 확인했습니다. 엔진이 만들어지면 `<html data-engine="ready">`가 붙고 상태 줄이 "오디오 엔진 준비됨"으로 바뀝니다 |
| 오프라인 렌더 | 메트로놈 데모 소리 | 같은 엔진을 `OfflineAudioContext`에 연결해 실시간보다 빠르게 구워 `audio/metronome-demo.wav`(8초)로 소리를 확인했습니다 |

순수 계산과 가짜 컨텍스트 시험은 함수 문서(104 ~ 114)의 §4에 있습니다.

## 5. 시험으로 찾아 고친 빈틈
| 함수 | 빈틈 | 고친 것 |
|---|---|---|
| 108 `Transport` | 기본 타이머가 `this.setTimer(...)`로 전역 `setInterval`을 부르면 `this`가 Transport가 되어 "Illegal invocation"이 나고, **브라우저에서 재생이 되지 않았습니다** | 기본값을 `function (fn, ms) { return setInterval(fn, ms); }`로 감싸 `this`와 무관하게 부르도록 했습니다 |
