## 1. 하는 일
클립 **오른쪽 끝을 끌었을 때의 새 길이**를 돌려줍니다. 격자에 맞추고, **최소 길이는 한 칸**(Alt일 땐 1틱)을 지킵니다.

> 새 길이 = max(한 칸, 격자에 맞춘 (지금 길이 + 끈 거리))

| 지금 길이 | 끈 거리 | 한 칸 | 새 길이 |
|---|---|---|---|
| 960 | 0 | 960 | 960 (제자리) |
| 960 | +1,000 | 960 | 1,920 |
| 1,920 | -700 | 960 | 960 |
| 1,920 | -5,000 | 960 | 960 (한 칸에서 멈춤) |
| 100 | -500 | 1 (Alt) | 1 (최소 1틱) |
| 100 | +37 | 1 (Alt) | 137 |
| 240 | -500 | 80 (1/16 셋잇단) | 80 |

```
1,920 에서 왼쪽으로 쭉 끌기
├────────────────────┤
        ◀────────────
├─────┤  960 (한 칸에서 멈춤, 안 지워짐)
```

## 2. 코드
```js
export function resizeClipLength(lengthTick, deltaTicks, stepTicks) {
  return Math.max(stepTicks, snapTick(lengthTick + deltaTicks, stepTicks));
}
```
**최신 문법으로 쓰면** (공부용)
```js
export const resizeClipLength = (lengthTick, deltaTicks, stepTicks) =>
  Math.max(stepTicks, snapTick(lengthTick + deltaTicks, stepTicks));
```
| 최신 문법 | 실제 코드 | 뜻 |
|---|---|---|
| 화살표 함수 | `function` 선언 | 같은 동작입니다 |

## 3. 왜 이렇게
| 선택 | 이유 |
|---|---|
| 최소 = 한 칸(2026-10-14 사용자 결정) | 스냅이 켜져 있으면 격자선까지만 줄어드는 것과 자연스럽게 맞습니다. 화면에서 계속 보입니다 |
| Alt 는 최소 1틱 | Alt 는 격자를 무시하니 한 칸이 1이라 그대로 1틱까지 줄어듭니다. 규칙을 따로 만들지 않아도 됩니다 |
| `Math.max(stepTicks, …)`를 나중에 | 격자에 맞춘 뒤 올려서 결과가 항상 한 칸 이상이고, 격자 위 값입니다 |
| 클립을 지우지 않음 | 최소보다 더 끌어도 멈추기만 합니다. 삭제는 Delete 키가 맡아서 실수로 사라지지 않습니다 |
| `snapTick()`을 그대로 씀 | 격자 맞추기가 한 곳에서 나오고, `stepTicks`가 0이면 그 오류가 전해집니다 |

## 4. 시험 (Node에서 직접 실행, 14개 통과)
| 확인 | 결과 |
|---|---|
| 제자리(0), 늘리기(960+1,000→1,920), 줄이기(1,920-700→960) | ✔ |
| 한 칸 밑으로 줄여도 멈춤(1,920-5,000→960, 960-960→960) | ✔ |
| 셋잇단 1/16 칸(80) 최소·늘리기 | ✔ |
| Alt(step 1): 100-50→50, 최소 1틱, 늘리기 자유 | ✔ |
| 여러 마디 늘리기(960+3,900→4,800) | ✔ |
| step 0·delta `NaN` → 오류 | ✔ |
