## 1. 하는 일
초 단위의 작업 시간을 `9h 00m` 같은 글자로 바꿉니다. 다음 함수(74번 `renderRecentProjects`)가 세 곳에서 씁니다: 프로젝트 줄의 7일 합계, 맨 위의 전체 합계, 막대에 마우스를 올렸을 때 나오는 안내(`… · 2h 30m`).

| 입력 (초) | 결과 | 설명 |
|---|---|---|
| `32400` | `9h 00m` | 9시간 |
| `17100` | `4h 45m` | 4시간 45분 |
| `1800` | `0h 30m` | 30분 (시간이 0이어도 `0h`를 씁니다) |
| `300` | `0h 05m` | 분은 항상 두 자리 |
| `360000` | `100h 00m` | 시간은 자릿수 제한이 없습니다 |
| `3590` | `1h 00m` | 59.8분을 분 단위로 **반올림**합니다 |
| `29`, `30` | `0h 00m`, `0h 01m` | 30초부터 1분으로 올림 |
| `-100`, `NaN`, `undefined`, `null` | `0h 00m` | 이상한 값은 0으로 봅니다 |

## 2. 언제 쓰나
| 호출하는 곳 | 화면 |
|---|---|
| 74 `renderRecentProjects` (예정) | 줄 오른쪽의 7일 합계(`9h 00m`), 카드 위의 전체 합계(`23h 00m`), 막대의 안내(`title`) |

## 3. 코드
**import**: 이 함수는 import를 쓰지 않습니다. 순수한 계산 함수입니다.

**함수**
```js
export function formatDuration(seconds) {
  const total = seconds > 0 ? Math.round(seconds / 60) : 0;
  const hours = Math.floor(total / 60);
  const minutes = total % 60;
  return hours + 'h ' + (minutes < 10 ? '0' : '') + minutes + 'm';
}
```

**최신 문법으로 쓰면** (공부용이며, 실제 코드는 위에 있습니다)
```js
export const formatDuration = (seconds) => {
  const total = seconds > 0 ? Math.round(seconds / 60) : 0;
  return `${Math.floor(total / 60)}h ${String(total % 60).padStart(2, '0')}m`;
};
```
| 최신 문법 | 실제 코드 | 뜻 |
|---|---|---|
| `` `${시간}h ${분}m` `` | `hours + 'h ' + … + 'm'` | 문자열에 값을 끼워 넣습니다 (템플릿 문자열) |
| `String(분).padStart(2, '0')` | `(minutes < 10 ? '0' : '') + minutes` | 두 자리가 되도록 앞에 `0`을 채웁니다 |
| 화살표 함수 한 줄 | `function` 선언 | 짧은 함수를 만드는 문법입니다 |

### 문법 풀이
| 식 | 뜻 | 예 |
|---|---|---|
| `seconds > 0 ? … : 0` | 0보다 클 때만 계산하고, 아니면 0입니다. `NaN`, `undefined`, 음수는 `> 0`이 거짓이라서 모두 0이 됩니다 | `NaN > 0`은 false |
| `Math.round(seconds / 60)` | 분 단위로 반올림합니다 | `3590 / 60 = 59.83` → `60` |
| `Math.floor(total / 60)` | 60으로 나눈 몫의 정수 부분이며, 시간입니다 | `105` → `1` |
| `total % 60` | 60으로 나눈 나머지이며, 분입니다 | `105` → `45` |
| `minutes < 10 ? '0' : ''` | 10보다 작으면 앞에 `0`을 붙입니다 | `5` → `05` |

## 4. 흐름
1. 0보다 큰 값이면 분으로 반올림하고, 아니면 0분으로 봅니다.
2. 전체 분을 60으로 나눠 시간과 분을 구합니다.
3. `시간h 분m` 모양으로 이어 붙입니다. 분이 한 자리이면 앞에 `0`을 붙입니다.

## 5. 왜 이렇게
| 선택 | 이유 |
|---|---|
| 분 단위로 반올림 | 초를 따로 보여 주지 않으므로 가장 가까운 분으로 맞춥니다. 59.8분이 `0h 59m`으로 내려가는 것보다 `1h 00m`이 자연스럽습니다 |
| 먼저 전체 분을 구한 뒤 시간과 분으로 나눔 | 반올림한 값이 60분이 되는 경우(3590초)에도 `0h 60m`이 아니라 `1h 00m`이 나옵니다 |
| 이상한 값은 0 | 서버는 항상 0 이상의 정수를 주지만, 값이 비어 오더라도 화면에 `NaN`이 나오지 않게 합니다 |
| 시간은 자릿수를 제한하지 않음 | 7일 합계가 100시간을 넘을 수도 있고, 전체 합계는 더 커질 수 있습니다 |
| 영어 약자 `h`, `m` | HTML 예시와 같은 형식입니다. 사이트의 글자는 영어입니다 (2026-10-07 결정) |
