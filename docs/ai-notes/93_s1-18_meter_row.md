## 1. 무엇을 만들었나

DB에는 `meter_changes` 표가 이미 있었지만 모델과 API가 없었고, 화면의 Meter 줄은 예시 그림이었습니다.

| 기능 | 설명 |
|---|---|
| 모델과 API | `GET`, `PUT /projects/{id}/meter-changes`. 멤버는 조회, OWNER와 EDITOR만 통째 교체합니다. `GET /full`의 `meter_changes`도 채웁니다. |
| 검증 | 분자 1~32, 분모 1, 2, 4, 8, 16, 32, tick 1 이상, 같은 tick 중복 금지, 최대 500개입니다. |
| 박자 줄 | 구간 클릭으로 추가, 같은 마디 클릭으로 박자 순환, `Alt`+클릭으로 삭제, 400ms 모아 저장, 되돌리기 연결입니다. |
| 메트로놈 계산 | 변경점을 따라 강박 위치를 계산합니다 (JS 328). |

## 3. 설계 결정

| 결정 | 이유 |
|---|---|
| 템포 API와 같은 모양(통째 교체)으로 만듦 | 화면 코드와 시험을 그대로 따라 할 수 있습니다. |
| 화면 격자는 4/4 마디로 고정 | 마디 길이를 바꾸면 눈금자, 스냅, 클립 폭, 재생 위치가 모두 달라지는 큰 개편이어서 이번 범위에서 뺐습니다. |
| 변경점은 마디 경계에만 찍음 | 격자가 4/4 마디 단위라 중간에 찍어도 보이는 위치가 맞지 않습니다. |
