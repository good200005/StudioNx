## 2. 점검 방법
| 항목 | 내용 |
|---|---|
| 도구 | Chrome 헤드리스와 DevTools 프로토콜(CDP)을 썼습니다. 개발 서버(`localhost:8000`)에서 페이지를 열고 `<html data-theme>`를 바꿔 가며 캡처했습니다 |
| 범위 | 7개 화면 × PC(1440×900)와 모바일(390×844) × 다크와 라이트 = 28장 |
| 자동 검사 | 가로 넘침, 콘솔 오류와 예외, 4xx와 5xx 요청, 중복 `id`, `alt` 없는 이미지, 라벨 없는 입력칸, 이름 없는 버튼, 24px보다 작은 누르는 영역(모바일) |
| 눈으로 확인 | 캡처를 보면서 글자 대비, 배치가 깨졌는지, 문구를 확인했습니다 |

## 3. 찾은 문제와 수정
| # | 문제 | 원인 | 수정 | 파일 |
|---|---|---|---|---|
| 1 | 라이트 테마에서 버튼에 마우스를 올리면 글자가 사라짐 (Check, Close, Cancel, 탈퇴 버튼) | hover 면이 `#ffffff`로 고정되어 있고, 글자는 바탕색(라이트에서는 거의 흰색)이었습니다 | 반전 색 토큰 `--c-invert`(다크는 흰색, 라이트는 먹색)와 `--c-invert-accent`(반전 면 위의 보라)를 추가해서, `.btn--primary`, `--ghost`, `--danger`의 hover가 토큰을 쓰게 했습니다 | `tokens.css`, `base.css` |
| 2 | 라이트 테마의 404, 403 오류 페이지에서 흐린 숫자가 거의 보이지 않음 | 다크 글자색 `rgb(244 243 247 / .14)`를 그대로 썼습니다 | `color-mix(in srgb, var(--c-ink) 14%, transparent)`로, 테마 글자색을 기준으로 흐리게 했습니다 | `pages/error.css` |
| 3 | 탈퇴 안내가 오늘 내린 결정과 다름 ("프로젝트가 지워진다") | 결정하기 전의 문구였습니다 | "다시 로그인할 수 없음, 내 프로젝트는 협업자를 위해 남음, 3일 뒤 같은 이메일로 다시 가입 가능"으로 고치고, 확인창 문구도 맞췄습니다 | `userInfo.html` |
| 4 | 모바일에서 Show, Remove, + View More, Edit profile, All projects 버튼의 높이가 20~22px | 글자 높이만큼만 영역이 잡혔습니다 | `.text-link`, `.pw__toggle`에 `min-height: 24px` (WCAG 2.2 2.5.8 최소 크기) | `base.css`, `auth.css` |

> 다크 테마의 모양은 바뀌지 않습니다 (`--c-invert`의 다크 값이 이전과 같은 `#ffffff`이고, `--c-invert-accent`는 이전의 `--c-violet`과 같은 값입니다).

## 4. 문제가 없거나 그대로 둔 것
| 항목 | 판단 |
|---|---|
| 콘솔 오류, 실패한 요청, 중복 `id`, 가로 넘침 | 28장 모두 없습니다 |
| 홈 첫 화면의 띠(SVG)가 화면 밖까지 그려짐 | 의도한 장식이며, 바깥 상자가 잘라 내므로 가로 스크롤이 생기지 않습니다 |
| 푸터 이메일 링크의 높이 14px | 문장 안의 링크라서 최소 크기의 예외입니다 |
| 문의 동의 체크박스 18px, 숨긴 사진 입력칸 | 라벨이나 버튼이 함께 눌리므로 실제 영역은 충분합니다 |
| 마이페이지와 나의 프로젝트의 헤더가 Sign In / Join Us로 보임 | 로그인 상태 전환은 JS(`initAuthState`, P1-07)가 할 일이며, 화면의 문제가 아닙니다 |

## 6. 자주 받을 질문 대비
- **Q. 왜 hover 색을 테마마다 따로 쓰지 않고 토큰을 만들었나요?** 같은 규칙(`:root[data-theme="light"]`, 시스템 설정)을 파일마다 반복하지 않으려는 것입니다. 토큰 두 개만 테마별로 정의하면 버튼 3종이 모두 따라갑니다.
- **Q. `color-mix`는 모든 브라우저에서 되나요?** 최신 Chrome, Edge, Firefox, Safari 모두 지원합니다 (2023년부터).
- **Q. 점검 스크립트는 어디에 있나요?** 일회성 점검이라 저장소에 넣지 않았습니다. 다시 필요하면 같은 방법(CDP 캡처 + 자동 검사)으로 만들 수 있습니다.
