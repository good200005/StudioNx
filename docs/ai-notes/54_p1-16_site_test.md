## 2. 시험 중 있었던 일
- 처음 가입 요청이 422였습니다. 서버의 처리방침 버전(`2026-10-08`)이 시험 스크립트가 보낸 값(`2026-10-05`)보다 새 것이어서 `privacy_version: outdated`로 거절한 것입니다. **서버는 정상**이고, 시험 스크립트의 값을 고쳤습니다.
- 서버의 로그 파일 경로를 잘못 지정해서 서버가 뜨지 않은 적이 있었습니다. 경로를 고쳐서 다시 띄웠습니다.
- 시험 스크립트를 한 번 끝까지 돌리지 못해 회원이 남았는데, 남은 부분(07, 08)을 따로 돌려서 정리했습니다.
