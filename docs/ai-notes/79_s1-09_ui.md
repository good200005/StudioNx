## 1. 실행 결과
시퀀서 화면을 `?projectId=` 로 열면 트랙 목록이 실제 값으로 다시 그려지고, 트랙을 펼치면 Instrument · Effects · Connect · Mixer 네 칸이 서버 값으로 채워집니다. 악기와 이펙트를 고르기 창에서 골라 붙이고, 카드의 노브를 끌어 값을 고치고, 카드를 끌어 이펙트 순서를 바꾸고, 카드를 눌러 상세 설정 창에서 그룹 탭과 전체 파라미터, 프리셋, A/B 비교를 다룰 수 있습니다. 고친 값은 모두 서버에 저장됩니다.

`?projectId=` 가 없으면 **데모 모드**로 열려 studioNx.html 의 예시 화면을 그대로 두고 노브 · 페이더 · 팬만 화면에서 움직입니다(저장 없음). 이때 카드의 ＋ 를 누르면 안내 알림이 뜹니다.

이번 작업은 **화면(프런트)** 입니다. 백엔드 경로와 시드는 78(226~242)에서 이미 만들었고, 이 화면이 그 경로를 그대로 씁니다. 소리(Web Audio)와 미터의 진짜 값, 그리고 Connect 링크 저장은 다음 작업으로 미뤘습니다.

## 10. 자주 받을 질문 대비 (Q/A)
Q. 왜 예시 화면을 그대로 두고 값만 덮나요?

A. studioNx.html 의 예시가 CSS 와 펼침 배선의 기준입니다. 실제 값으로 줄과 칸을 다시 그리되, 칸에는 `.is-live` 를 붙여 예시 배선이 건드리지 않게 했습니다. 그래서 한 벌의 CSS 로 두 모드를 함께 다룹니다.

Q. 값을 끌 때마다 저장하나요?

A. 아닙니다. 끄는 동안에는 화면만 바뀌고, 손을 놓는 순간 한 번 저장합니다. 휠과 화살표 키는 한 칸씩이라 바로 저장합니다(257).

Q. 이펙트 순서를 맞바꿀 때 요청이 몇 번 나가나요?

A. 세 번입니다. 옮기는 카드를 빈 칸 100 으로 비켜 두고, 사이 카드를 한 칸씩 밀거나 당긴 뒤 마지막 자리로 옮깁니다. 이미 찬 칸에 넣으면 400 이라 한 번에 맞바꿀 수 없습니다(260).

Q. 화면은 어떻게 시험했나요?

A. 헤드리스 Chrome 으로 실제 서버(8001)와 실제 DB 에 붙어, 로그인 · 프로젝트 열기 · 펼치기 · 붙이기 · 떼기 · 순서 바꾸기 · 모달 열기까지 사람처럼 눌러 40건을 확인했습니다. 시험은 끝나면 DB 상태를 원래대로 되돌립니다(`docs/handoff/s1-09_tests/ui.mjs`).
