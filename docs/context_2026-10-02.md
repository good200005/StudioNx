### 3.2 개발 환경 · DB
- `studionx/`에 FastAPI 뼈대, `.venv`(Python 3.13), `.env.example`, Sentry 연결(DSN은 비어 있음)을 만들었습니다.
- MySQL database `studionx`, 앱 계정 `studionx_app`을 만들었습니다. 01~06 SQL과 2026-10-02·10-03 변경 SQL까지 **로컬 DB에 실행 완료(35개 테이블)**입니다. DB 명령은 `mysql`이 PATH에 없으면 `.venv`의 `pymysql`로 실행할 수 있습니다.
- DB 실행 명령은 PowerShell용 `mysql ... -e "source 파일"` 방식입니다. `<`는 PowerShell에서 오류가 납니다.
