### 3.2 개발 환경 · DB
- `studionx/`에 FastAPI 뼈대, `.venv`(Python 3.13), `.env.example`, Sentry 연결(DSN은 비어 있음)을 만들었습니다.
- MySQL database `studionx`, 앱 계정 `studionx_app`을 만들었습니다. 01~06 SQL과 2026-10-02 변경 SQL까지 **로컬 DB에 실행 완료(34개 테이블)**입니다.
- DB 실행 명령은 PowerShell용 `mysql ... -e "source 파일"` 방식입니다. `<`는 PowerShell에서 오류가 납니다.

### 3.4 결정 사항
| 결정 | 내용 |
|---|---|
| 관리자 화면 | **SQLAdmin**을 `/admin`에 연결, `users.role = 'ADMIN'`만 접근. 공지 작성과 문의 답변을 여기서 처리 (작업 P1-21) |
| `dev_notes` | Development 공지 테이블. 메인 페이지는 공개된 최신 4건을 읽음 (`GET /api/v1/dev-notes?limit=4`) |
| `inquiries` | `name` NULL 허용, `privacy_agreed_at` 추가 |
| 로그인 화면 | **별도 `login.html` 없음** → `home.html`의 로그인 모달. 로그인이 필요한 페이지는 `home.html#login?next=<원래 페이지>`로 보내 모달 자동 열기 (P1-06 화면, P1-07 JS) |
| 자동 로그인 | 모달의 체크박스. 체크 = 리프레시 쿠키 **3일** 유지, 미체크 = 세션 쿠키. 다시 접속하면 `home.html`(자동 이동 없음) + 헤더 버튼이 My Page / My Projects로 바뀜 |
| 공통 헤더·푸터·로그인 모달 | `static/partials/`의 HTML 조각 하나씩 → 페이지는 `<div data-include="static/partials/header.html">` 한 줄, 페이지 JS 맨 위 `await includePartials()` (`core/include.js`, 사용자 요청으로 AI 구현). **새 페이지도 이 방식으로**, 고칠 때는 조각 파일만. 설명 `docs/ai-notes/10_common_partials.md` |
| View More hover 색 | 진한 보라 대신 밝은 보라 `#a383ff` (대비 때문) |
| 디자인 도구 | impeccable 스킬 사용 (`PRODUCT.md`, `.impeccable/`). Playwright 검증은 dev 서버(8000)로 (`file://` 막힘) |

## 5. 사용자 성향 · 주의 사항
| 항목 | 내용 |
|---|---|
| 쉘 | Windows **PowerShell 5.1**에서 명령 실행. 안내 명령은 PowerShell 호환으로 쓰고, `<` 리디렉션은 쓰지 않음. 경로는 저장소 루트(`StudioNx/`) 기준 |
| PDF 뷰어 | 한PDF로 열어 둔 PDF는 잠겨서 빌드가 덮어쓰지 못함 → `build.js`가 "저장 실패" 오류를 냄. 닫고 다시 빌드 |
| 요청 방식 | 수정 사항을 PDF(빨간 박스 주석)로 `frontend-reference/images/main page reference/`에 넣고 구현을 요청함 |
| 말투 | 짧은 지시("커밋하고 푸시 및 머지 ㄱㄱ"). 커밋·푸시·머지를 한 번에 요청하는 경우가 많음 |
| 비밀 정보 | `.env`, `docs/googlesheetAPI.txt`, `docs/studionx-*.json`은 `.gitignore` 대상. 내용을 출력하거나 커밋하지 않음 |
| 오래된 자료 | 문서·PDF·docx 중 하나만 갱신되는 실수가 있었음 → md·PDF·docx를 함께 확인 |
