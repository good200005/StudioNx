## 2. 처리방침 전문 (한국어 초안)
> 화면(`privacy.html`, 영어)에 같은 내용이 들어가 있습니다. 이 문서를 고치면 화면도 함께 고치고 버전을 올립니다.

### 2.1 개요
Studio Nx(이하 "서비스")는 브라우저에서 쓰는 음악 작업 도구입니다. 서비스는 아래 목적에 필요한 만큼만 개인정보를 받고, 광고나 마케팅에 쓰지 않으며 판매하지 않습니다.

### 2.2 받는 정보와 이유
| 언제 | 받는 정보 | 이유 | 처리 근거 (GDPR) |
|---|---|---|---|
| 회원가입 | 이메일, 닉네임, 비밀번호, 처리방침 동의 시각·버전 | 계정 만들기·로그인. 비밀번호는 원문을 저장하지 않고 되돌릴 수 없는 형태(bcrypt 해시)로만 저장 | 계약 이행 |
| 회원 정보 수정 | 프로필 사진 (jpg·png·webp, 2MB 이하) | 내 프로필·협업 화면에 표시 | 계약 이행 (선택 항목) |
| 로그인 | 마지막 로그인 시각 | 계정 보호, 오래 안 쓴 계정 확인 | 정당한 이익 |
| 서비스 이용 | 프로젝트(제목·설명·BPM 등), 작업 세션 시간, 저장 용량 사용량 | 프로젝트 저장, 마이페이지 작업 시간·용량 표시 | 계약 이행 |
| 문의 | 답장 받을 이메일, 제목, 내용, 처리방침 동의 시각 (로그인 상태면 회원 번호) | 문의 확인·답변 | 동의 |
| 오류가 났을 때 | IP 주소, 브라우저·운영체제 종류, 요청 주소, 오류 내용 | 오류 원인 분석 (§2.6 Sentry) | 정당한 이익 |

> 업로드한 오디오 파일, AI 분석 기록, 협업 채팅 등은 해당 기능이 생길 때(Phase 2 이후) 이 표에 추가하고 공지합니다.

### 2.3 쿠키와 브라우저 저장소
| 이름 | 종류 | 내용 | 기간 |
|---|---|---|---|
| `snx_refresh` | 쿠키 (HttpOnly) | 로그인 유지용 토큰. 화면 스크립트가 읽을 수 없음 | 자동 로그인 체크 시 3일, 아니면 브라우저를 닫을 때까지 |
| `snx-intro` | 세션 저장소 | 첫 화면 로딩 애니메이션을 이미 봤는지 | 탭을 닫을 때까지 |
| `studionx.readyDismissed` | 로컬 저장소 | 마이페이지 "Ready to start" 배너를 닫은 프로젝트 번호 | 직접 지울 때까지 |

광고·방문 분석용 쿠키는 쓰지 않습니다. 브라우저 설정에서 쿠키를 막으면 로그인이 유지되지 않습니다.

### 2.4 보관 기간과 파기
| 정보 | 보관 기간 |
|---|---|
| 회원 정보 | 탈퇴할 때까지 |
| 탈퇴한 계정 | 탈퇴 즉시 로그인 불가. **이메일·닉네임은 같은 값으로 바로 다시 가입하는 것을 막기 위해 3일 보관한 뒤 비움** (D5). 프로필 사진은 탈퇴 때 삭제 |
| 탈퇴한 회원이 만든 프로젝트 | 함께 작업한 다른 회원을 위해 남기고, 만든 사람은 "탈퇴한 회원"으로 표시 |
| 문의 | 답변 후 1년. 답변하지 않은 문의는 받은 뒤 1년 (2026-10-08) |
| 오류 기록 (Sentry) | Sentry의 보관 기간이 지나면 자동 삭제 (현재 요금제 기준 — 배포 전 확인) |

전자 파일은 되살릴 수 없는 방법으로 지웁니다.

### 2.5 다른 곳에 주는 정보 · 판매하지 않음
법에 따른 요청이 있을 때를 빼면, 개인정보를 다른 사람이나 회사에 주지 않습니다. 개인정보를 **팔지 않고**, 맞춤 광고를 위해 공유하지도 않습니다 (CCPA/CPRA의 "판매"·"공유" 포함).

### 2.6 처리 위탁 · 국외 이전
| 받는 곳 | 나라 | 넘어가는 정보 | 이유 | 보관 기간 |
|---|---|---|---|---|
| Sentry (Functional Software, Inc.) | 미국 | 오류가 난 요청의 IP 주소(D1), 브라우저 정보, 오류 내용. 비밀번호·로그인 토큰·쿠키는 보내기 전에 지움 | 오류 분석 | §2.4 |
| Google Fonts, jsDelivr (글꼴 제공) | 미국 등 | 페이지를 열 때 브라우저가 글꼴 파일을 받으면서 IP 주소가 전달됨 | 화면 글꼴 표시 — **정식 공개 전 자체 호스팅으로 없앰** (D6) | 각 회사 정책 |

국외로 넘어가는 정보는 해당 회사의 표준 데이터 보호 조항(EU 표준계약조항 등)으로 보호됩니다. 서버를 둘 호스팅 회사는 배포할 때 정해지며, 정해지면 이 표에 추가합니다.

### 2.7 이용자의 권리
사는 곳과 상관없이 아래를 요청할 수 있습니다 (GDPR 15~22조, CCPA, 개인정보 보호법 35~37조).

| 권리 | 방법 |
|---|---|
| 열람 · 사본 받기(이동권) | 이메일 요청 → 흔히 쓰는 형식(JSON 등)으로 제공 |
| 정정 | 닉네임·사진은 Profile 화면에서 바로, 그 밖은 이메일 |
| 삭제 | Profile 화면 맨 아래 **Delete account** |
| 처리 제한 · 반대 | 이메일 요청 |
| 동의 철회 | 문의처럼 동의로 받은 것은 언제든 철회 (이메일) |
| 감독기관 신고 | 한국 개인정보보호위원회, EU·영국은 거주 국가의 감독기관 |

요청에는 **30일 안에** 답하고, 권리를 썼다는 이유로 불이익을 주지 않습니다.

### 2.8 안전하게 지키는 방법
| 방법 | 내용 |
|---|---|
| 비밀번호 | bcrypt 해시로만 저장 |
| 로그인 토큰 | 짧게 쓰는 토큰은 화면 메모리에만, 유지용 토큰은 스크립트가 읽을 수 없는 쿠키에 |

| 오류 기록 | 비밀번호·토큰·쿠키는 Sentry로 보내기 전에 지움 |
