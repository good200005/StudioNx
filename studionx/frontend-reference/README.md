# frontend-reference/ — 프론트엔드(HTML/CSS) 레퍼런스

AI가 HTML/CSS를 작성하기 전에 **반드시 먼저 확인하는 폴더**입니다. (기획서 AI 규칙: "레퍼런스를 관련 디렉토리에서 확인")

| 폴더 | 넣을 것 |
|---|---|
| `images/` | 참고 화면 스크린샷·시안·무드보드 (png, jpg, webp, gif) |
| `code/` | 참고할 HTML/CSS 조각, 마음에 드는 스타일 예시 |
| (이 파일) | 아래 "메모"에 원하는 방향을 적어 두기 |

> 이 폴더는 `frontend/` 밖에 있어서 **웹으로 서빙되지 않습니다**. 실제 페이지에 쓸 이미지는 `frontend/static/assets/`에 둡니다.

## 파일 이름 규칙 (권장)
`{페이지}_{내용}.{확장자}` — 예: `studioNx_track-accordion.png`, `home_hero.png`, `common_button-style.css`
- 페이지: `home`, `login`, `join`, `myPage`, `userInfo`, `myProject`, `studioNx`, 공통은 `common`
